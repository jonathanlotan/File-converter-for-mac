# Security

Swivel opens files people drag onto it, so problems such as a crafted archive writing outside
its folder, or a file that makes the app run something, matter.

Please report a vulnerability privately with GitHub's
[private vulnerability reporting](https://github.com/jonathanlotan/Swivel/security/advisories/new)
rather than in a public issue. You'll get a reply within a few days, and a fix will be
released as soon as it's ready, with credit to you if you'd like.

Only the latest release is supported.
