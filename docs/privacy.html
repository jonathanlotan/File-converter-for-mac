Privacy and terms

Swivel, the file converter for macOS. Effective 19 October 2026.

Swivel collects nothing. It has no network code, so it can't send or receive anything, and there is no account, no analytics, no crash reporting and no update check.

Your files

  • Files are converted on your Mac with Apple's frameworks and tools that come with macOS. They are never uploaded.
  • Results are saved next to the originals. Originals are never changed, and nothing is overwritten.
  • When macOS asks whether Swivel may use your Desktop, Documents or Downloads folder, it's so the result can be saved next to the file you dragged.
  • If you use Share (AirDrop, Mail, Messages and so on), macOS hands the files to the service you pick, and that service's own privacy policy applies.

What Swivel stores

Only your settings, on your Mac, in ~/Library/Preferences/io.github.jonathanlotan.Swivel.plist. Deleting the app and that file removes everything.

How you can check

The source code is public. Its tests inspect the built app, its Finder extension and the swivel command for networking APIs and fail if any are linked. A network monitor such as LuLu or Little Snitch will show Swivel making no connections.

This website

These pages are hosted on GitHub Pages. They use no cookies, no analytics and no third-party scripts, and the browser tryout reads none of your files. GitHub may keep server logs; see the GitHub privacy statement.
